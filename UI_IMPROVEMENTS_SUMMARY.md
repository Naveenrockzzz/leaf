## 🎨 Design System Used

### Colors:
```css
Primary Blue: #2563eb (blue-600)
Purple Accent: #9333ea (purple-600)
Green Success: #16a34a (green-600)
Red Accent: #ef4444 (red-500)
Gray Shades: #f9fafb, #e5e7eb, #6b7280
```

### Gradients:
```css
Blue to Purple: from-blue-600 to-purple-600
Blue to Blue: from-blue-600 to-blue-700
Green to Green: from-green-600 to-green-700
Background: from-gray-50 to-blue-50
```

### Border Radius:
```css
Small: rounded-xl (12px)
Medium: rounded-2xl (16px)
Large: rounded-3xl (24px)
Full: rounded-full
```

### Shadows:
```css
Small: shadow-sm
Medium: shadow-lg
Large: shadow-2xl
Hover: hover:shadow-2xl
```
